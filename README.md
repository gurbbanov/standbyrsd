# standbyrsd
<p align="center">
  <img width="171" height="171" alt="standbyrsd-logo" src="https://github.com/gurbbanov/standbyrsd/blob/master/icons/standbyrsd-icon.png" />
</p>

standbyrsd is simple cross-platform GUI application built with Rust and [Iced](https://github.com/iced-rs/iced)

## features
- clock display
  
  standbyrsd includes 5 styles - analogue, rectangular analogue, minimal, digital and world clock
- calendar

  shows monthly and compact date views
- weather forecast

  fetches weather in minimal, detailed and daily forecast styles. each weather can be pointed to any city independently
- media player

  includes two media player styles - compact and full-screen

- localization

  standbyrsd speaks 11 languages - English, Russian, Azerbaijani, Turkish, Georgian, Kazakh, German, Spanish, French, Japanese and Chinese

- themes

  standbyrsd currently ships with 2 themes — classic and red dark. both can switch automatically by sunrise/sunset or a custom time schedule. more themes are coming in future releases
- persistence

  standbyrsd remembers all settings, carousel position and city preferences across sessions
- platforms

  standbyrsd runs on Windows, macOS and Linux with a built-in auto-updater

- scalability

  standbyrsd scales all UI elements with window size, looking sharp at any resolution or screen density
